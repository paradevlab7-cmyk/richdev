# 투찰가 분석 확장 기능 QA 기록

검토일: 2026-08-15

## 수동 화면 확인

`/analysis` 화면을 데스크톱 1280×720 뷰포트에서 확인했다. 분석 조건 카드에 **기본 원가**, **부대비용**, **수수료율**, **목표 마진율** 네 입력란과 안내 공식 `총원가 ÷ (1 - 목표 마진율 - 수수료율)`이 표시되며, 부대비용과 수수료가 기존 투찰가 분석 입력 흐름을 가리지 않는 것을 확인했다.

## 기능 검증 근거

| 항목 | 검증 방식 | 결과 |
|---|---|---|
| 원가·부대비용·수수료 반영 | 시나리오 계산 단위 테스트 및 분석 화면 상호작용 테스트 | 통과 |
| 시나리오별 예상 이익금 | 화면 상호작용 테스트 | 통과 |
| 추세 30·90·180일 전환 | tRPC 입력 전달 및 화면 버튼 상호작용 테스트 | 통과 |
| Excel 내보내기 | 다중 시트 데이터 생성 단위 테스트 및 버튼 호출 테스트 | 통과 |
| PDF 내보내기 | 화면 보고서 캡처 함수 및 PDF 버튼 호출 테스트 | 통과 |

브라우저 자동 화면 캡처는 다운로드 선반의 파일 저장 완료 여부를 노출하지 않으므로, 실제 파일 생성은 컴포넌트의 클릭 흐름과 내보내기 데이터 생성 테스트로 검증했다. 배포 후 사용자는 분석 결과가 표시된 상태에서 **Excel** 또는 **PDF** 버튼을 눌러 브라우저 다운로드 목록에서 파일을 직접 확인할 수 있다.
