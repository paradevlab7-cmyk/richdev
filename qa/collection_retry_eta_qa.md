# 수집 이력 재시도·오류 필터·예상 완료 시각 QA 기록

검토일: 2026-08-15

## 화면 확인

`/collections` 전체 화면에서 수집 설정, 일별 성공·실패 차트, 최근 수집 실행 목록을 확인했다. 목록 상단의 진행 중인 개방표준 실행은 `91 / 180` 페이지, `9,100 / 17,966`건 진행률과 함께 **개방표준 이어수집 예상 완료** 시각 및 남은 예상 시간·건수를 표시했다.

## 기능 확인

실패 상태 행은 오류 메시지에서 네트워크·인증·호출 제한·시간 초과·API 응답·기타 유형을 자동 분류한다. 유형 필터는 해당 실패 행만 남기며, `재시도`는 같은 실행 ID의 기존 수집 구간과 다음 페이지를 이어받도록 서버에 요청한다. 화면은 재시도 완료 후 수집 이력과 일별 통계를 새로 고친다.

## 자동 검증 근거

`collectionRunInsights.test.ts`는 오류 분류와 처리량 기반 ETA 계산을 검증한다. `CollectionHistory.test.tsx`는 오류 유형 필터, 실패 재시도 요청, 개방표준 ETA 렌더링을 검증한다. `bidAnalysisRouter.test.ts`는 재시도 API가 현재 사용자와 실행 ID를 전달하는지 검증한다.
